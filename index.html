How the notation works

    

      
BlockWidthCharactersMeaning

      
PP2lettersstone identity

      
G1digitquality grade

      
HH2digit then letterhue

      
SS2letterscutting shape

    

    
    
      
  • No separators needed: a lone digit can only be a
        grade, a digit followed by a letter can only start a hue, letters can
        only be a shape — at most one reading of a token is structurally
        valid.
    • 
      
  • Defaults keep codes short: a block equal to the
        stone's default — determined from occurrence counts in the actual
        stone history — is omitted, so frequent stones write in two
        characters.
    • 
      
  • Colour-bearing stones (Blue Topaz...) declare an
        implied hue: their tokens never write it, and writing a
        different hue is refused as a double colour.
    • 
      
  • A product's colour code joins the distinct stone
        tokens with +: center stone first, then
        heaviest single stone descending, ties by token.
    •
