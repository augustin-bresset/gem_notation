From today's codes

      the new description — a draft to validate. Merged: several
      of today's codes become one description (duplicates, drilling). To
      confirm: a reading that needs someone who knows the stones. Conflict: the
      type and the shade disagree.

How it works

    
    
      
  1. Every stone is described in full — family, colour,
        grade, treatment, effect (and shape and size for the stock). Each
        family lists the values it accepts: Reconstructed exists for
        turquoise or coral, not for sapphire. Blue Topaz is no longer
        a stone of its own but Topaz + Blue, so it keeps its grade.
    2. 
      
  2. The code tells the stone and its colour — and
        little more. Each family writes its colour wherever several are in
        use, except its default colour: a diamond is white unless
        told otherwise, so the white diamond is DTS
        and the brown one DTSBR. The grade is written
        only where today's product codes already write it — sapphire
        (SAPL), topaz (BTA),
        citrine (CITA), ruby and emerald
        (RU2, EM2). Tones
        read either way — A · AA · AAA · AAAA as in the
        stock codes, or 1A · 2A · 3A · 4A; product
        codes today mostly write 2A,
        3A, 4A (79 to 100 %)
        but keep A for the light tone (99 %). The
        switch at the top writes every code one way or the other; a code is
        read in any of them.
    3. 
      
  3. Every variety keeps today's code: the stock code,
        type then shade, that everyone already reads, without what the family
        does not write — Peridot is PER whatever its
        grade, the amethyst AME. Stones that were the
        same thing under two codes take the most used one
        (SAPLM → SAPL).
        A combination never seen before is written with today's pieces
        (TOPPK, a pink topaz) and flagged.
    4. 
      
  4. A product code is the model, its varieties — center
        stone first, then heaviest single stone — and the metal:
        R1048-SAPM+DTS/W, as written today.
    5. 
      
  5. A variant index settles the rest. Products of one
        model with the same codes but other stones — another grade, size or
        count — are numbered in creation order, the first without index:
        R1048-SAPM+DTS/W-2. The same stones in
        another metal keep their number. The index stays small: 92 % of
        products have none, 99.5 % stay at 3 or less; the few beyond 9 are
        all-diamond models whose versions differ by diamond count and size.
    6. 
    

    
Sources: the stone dictionaries and the usage
      counts of the production history (aggregates only — no product data is
      published). The earlier token notation is kept in the
      design study.
